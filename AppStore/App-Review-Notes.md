# App Review Notes

Orbit Rush can be fully played in Solo mode without creating an account or making a purchase.

Optional non-consumable purchases are available in the Orbit Shop. The Restore Purchases action is visible at the bottom of that screen. Orbit Rush Pro includes multiplayer and both cosmetic style packs.

Worldwide multiplayer uses Apple Game Center. Nearby multiplayer requires two physical iOS devices on the same local network with Local Network permission enabled. On device one, choose Multiplayer → Create Game. On device two, choose Multiplayer → Find Nearby Game.

The optional photo feature uses Apple's system PhotosPicker. Selected images are used locally as planet textures and are not uploaded by the developer.

ReplayKit recording is started with the red record button and uses Apple's system preview for saving or sharing.

No advertising, analytics SDK or cross-app tracking is included.
